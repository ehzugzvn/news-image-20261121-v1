# THE DAILY WORLD — news-image-20261121 (v1)

A classic broadsheet front page summing up Saturday 21 November 2026 in one image: cream paper, black serif type and thin rules, with the full date large and unmistakable in the masthead and repeated in a small date line. The lead story — Russian missiles falling in Poland — sits large at the top with a standfirst and a small inset dot-matrix world map marking the top five events (Poland, Kyiv, Antalya, New York, Riyadh). Below it, a three-column layout carries about 38 stories in numbered cards grouped under region headers (Europe, Climate/COP31, North America, Middle East, Asia-Pacific, South Asia, Africa, Latin America, Health & Sport). The committed `entry.png` (1024×1024) is rendered by `render.py` using PIL and the Liberation fonts in `fonts/`; `main.py` (Python standard library only) copies the committed page to the output directory.
